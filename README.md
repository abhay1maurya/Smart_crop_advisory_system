🌾 Smart Crop Advisory System (Krishi Sahayak)
An AI‑based Decision Support System for Agriculture

📌 Project Overview
The Smart Crop Advisory System (Krishi Sahayak) is an academic project designed to assist farmers in making data‑driven agricultural decisions using Artificial Intelligence and Machine Learning.

The system provides intelligent recommendations related to:

Crop selection

Fertilizer usage

Plant disease detection

Weather‑based advisories

It aims to reduce guesswork in farming and promote sustainable and efficient agricultural practices.

🚀 Key Features
🌱 Crop Recommendation
Suggests the most suitable crop based on soil nutrients and weather conditions.

🧪 Fertilizer Recommendation
Recommends the appropriate fertilizer using crop, soil, and environmental data.

🌿 Plant Disease Detection
Detects crop diseases from leaf images using deep learning (CNN).

🌦️ Weather Advisory
Provides real‑time weather information and alerts.

🤖 Multilingual Chatbot
Assists farmers with queries in simple language.

📝 Blog & Community Module
Enables knowledge sharing between farmers and experts.

🛠️ Technologies Used
Backend: Python, FastAPI, Spring Boot

Frontend: HTML, CSS, JavaScript

Machine Learning: Scikit‑learn

Deep Learning: TensorFlow, Keras

Database: MySQL

APIs: Weather APIs, REST APIs

🧠 Models Included
Crop Recommendation Model

Uses ensemble machine learning techniques

Inputs: Soil nutrients & weather parameters

Fertilizer Recommendation Model

Classification‑based ML model

Trained on ~5,500 agricultural records

Plant Disease Detection Model

CNN based on MobileNetV2

34 disease classes

Trained on Kaggle using GPU

💻 How to Run (Basic)
Create a virtual environment / conda environment

Install required dependencies

Run the FastAPI services

Open the frontend and provide input data

Detailed instructions are provided in individual module README files.

📊 Dataset
Public agricultural datasets

Soil nutrient data (N, P, K, pH)

Weather data

Plant leaf image datasets
